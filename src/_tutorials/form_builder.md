## Step 1: Introduction to Shalom Cloud Form Builder
This tutorial introduces the Shalom Cloud Form Builder, which is typically used for tasks like membership renewal, religious school registration, or gathering opinions from the congregation.

#### Step 2: Advantages of Shalom Cloud Form Builder
Learn the advantages of using the Shalom Cloud Form Builder over commercial form-building applications, focusing on its integration into Shalom Cloud.

#### Step 5: Editing Questions in the Form
Edit existing questions one by one, reviewing fields such as order, required status, and question types.

#### Step 6: Exploring Question Types - Radio Button
Examine the radio button question type, which allows for minimal formatting and requires selecting one option.

#### Step 7: Exploring Question Types - Checkbox
